Wrap N coordinates to prevent precision loss (N-lane SIMD version of wrap).

Fast path: at normal game coordinates all lanes are within [-HALF_ROUND_OFF, HALF_ROUND_OFF), so the expensive div + floor + mul is skipped almost always.
