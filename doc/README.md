# Steel documentation

## Extensions

- [Create an extension](extensions/getting-started.md): build a configurable command,
  package its native library, and install it on a server.
- [Extension API](extensions/api.md): lifecycle, public types, hooks, world access,
  behaviors, generators, commands, and runtime operations.

The guides describe the API in this checkout. For complete applications, see the
[extension examples](../extension-example/README.MD) and
[Spleef extension](../extension-example/spleef/README.md). The
[API crate README](../steel-extension-api/README.md) also explains the native ABI
and binding implementation.

For actions, filters, and cross-extension ordering, start with the
[hook/filter example](../extension-example/hooks-and-filters/README.md).
