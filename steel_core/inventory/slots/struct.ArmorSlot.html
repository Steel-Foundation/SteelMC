Struct ArmorSlot 

Source 
pub struct ArmorSlot {
    base: NormalSlot,
    slot: EquipmentSlot,
}
Expand description

A NormalSlot that only accepts items equippable in its equipment slot, caps at one item, and respects the prevent-armor-change enchantment effect.
