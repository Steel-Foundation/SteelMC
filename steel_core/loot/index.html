Module loot 

Source
Expand description

Compiled loot generation and container filling. Loot tables compiled from vanilla data into Rust functions.

See LootTable for generation and LootTableBehaviorRegistry for handwritten Rust implementations. Callers can supply a vanilla random stream directly or use crate::world::World::with_loot_random for world-aware selection.
