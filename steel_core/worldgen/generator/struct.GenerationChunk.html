Struct GenerationChunk 

Source 
#[repr(transparent)]
pub struct GenerationChunk<'a, Phase> {
    chunk: &'a Chunk,
    phase: PhantomData<fn() -> Phase>,
}
Expand description

Stage-scoped access to the center chunk being generated.

The scheduler constructs this capability only after the chunk’s input status is published. It deliberately does not expose the underlying Chunk or its raw section storage, so status-sensitive writes stay tied to the operation that owns them.

ⓘ
use steel_core::worldgen::generator::{GenerationChunk, NoisePhase};

fn write_surface_column_during_noise(chunk: GenerationChunk<'_, NoisePhase>) {
    chunk.write_column(0, 0, &[]);
}
