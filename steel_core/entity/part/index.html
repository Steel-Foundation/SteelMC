Multipart entities, shaped after NeoForge’s PartEntity.

Vanilla has no shared base for EnderDragonPart, so engine code going through PartEntity never names a specific mob. Like vanilla’s ServerLevel.dragonParts, parts stay out of the entity manager: they are never sectioned, saved or sent to clients, which synthesize them from the parent’s ID (see crate::entity::EntityIdBlock).
