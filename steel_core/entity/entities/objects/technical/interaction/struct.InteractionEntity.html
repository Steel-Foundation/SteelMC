    base: EntityBase,

    attack: SyncMutex<Option<PlayerAction>>,
}
Expand description

An invisible, invincible, interactable entity which records when a player clicks on its bounding box. It is used in map-making or data packs, and its bounding box is customizable.

The dimensions of its bounding box (width and height) and whether it triggers a response from the player (response) can be accessed and/or modified with InteractionEntity::with_entity_data.

pub fn with_entity_data<R>( &self, f: impl FnOnce(&mut InteractionEntityDataView<'_>) -> R, ) -> R

Provides an exclusive view to the synced entity data to the given closure, which includes the dimensions of its bounding box (width and height), and whether it triggers a response from the player (response).

Do not attempt to lock entity data within the closure provided.
