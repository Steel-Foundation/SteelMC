Module perf 

Source
Expand description

Tick-phase performance recording behind /perf.

Vanilla profiles JVM metrics and writes a zip. Steel instead samples the per-tick and per-phase timings that the game loop already computes and writes them as raw per-tick JSON samples, leaving statistics to external tools. The report also carries the server, system and per-world context that vanilla writes to system.txt, server.properties.txt and gamerules.txt.
