Shared Java HashSet<BlockPos> bucket and tree-bin ordering.

Distinct hashes follow OpenJDK 25’s linked tree-bin order. BlockPos inherits Comparable<Vec3i>, so equal-hash ties use JVM identities. Steel preserves its existing deterministic policies: coordinate ordering for worldgen, and insertion indices for explosions (matching increasing JVM identities).
