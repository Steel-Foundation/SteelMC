Expand description

Registry of all data component types.

Stores metadata about each component type including how to serialize/deserialize them for network and persistent storage.

Fields§

Component entries indexed by network ID

Whether registration is still allowed

where T: Component + DowncastType + Clone + ToNbtTag + FromNbtTag + HashComponent,

Registers a component with custom network reader/writer functions.

Use this when the default WriteTo/ReadFrom implementations don’t match the network encoding (e.g., VarInt-encoded i32 components). NBT serialization still uses the type’s ToNbtTag/FromNbtTag impls.
