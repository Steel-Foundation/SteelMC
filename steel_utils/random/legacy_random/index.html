LegacyRandom
Legacy Minecraft random number generator based on a Linear Congruential Generator (LCG). This implementation mirrors Java’s java.util.Random which Minecraft originally used.
LegacyRandomSplitter
A positional random number generator factory for the legacy Minecraft LCG algorithm. This can create random sources based on position, hash, or seed.
