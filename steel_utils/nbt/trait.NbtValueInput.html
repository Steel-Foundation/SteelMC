Expand description

Numeric reads accepting any numeric tag, unlike simdnbt’s getters which return None when the tag type differs.

getIntOr(name, default) is int_value(name).unwrap_or(default) here, and getBooleanOr(name, false) is byte_value(name).is_some_and(|v| v != 0).
